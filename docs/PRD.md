# PRD — 产品需求

> 状态：草稿，内容取自 2026-11-10 批准的参赛方案，待项目负责人逐条确认。

## 要解决的问题
在 DEX 上持仓的交易者没有中心化交易所那种 OCO 单（止损和止盈绑成一对，一个成交另一个自动作废）。现在的凑合办法是自己盯盘，或者跑一个链下机器人：机器人要一直在线、要托管私钥，而且价格急跌时晚几秒成交就多亏一截。

本项目是 Reactive Omni Buildathon「Every Second Counts」赛道的参赛作品，评委是 Reactive 团队。

## 目标用户
1. **链上交易者**：在 Unichain 的 Uniswap v4 池子里持有代币，想预先设好止损和止盈，之后不用盯盘。
2. **Buildathon 评委**：想在链上看到完整链路（源事件 → reactive 交易 → callback），以及说明"为什么需要 1 秒出块"的延迟数据。

## 这一版要做的功能
按优先级：

1. **下 OCO 单**：用户存入代币，设止损价、止盈价、过期时间。
   验收：下单后代币托管在金库合约，链上有 `OrderCreated` 事件。
2. **止损自动成交**：池子价格跌到止损价时自动卖出，所得转给用户。
   验收：测试网上能看到源链 Swap、Lasna reactive 交易、目标链 callback 三笔交易，用户收到卖出所得。
3. **止盈自动成交**：价格涨到止盈价时自动卖出。验收同上。
4. **OCO 互斥**：一边成交后另一边作废，同一张单不会成交两次。
   验收：成交后再次触线不产生第二次卖出。
5. **移动止损**：止损价跟着最高价上移，回落超过设定距离时卖出。
   验收：价格先涨后跌，卖出价高于最初的止损价。
6. **取消和过期**：用户可随时取消并取回代币；过期后不再成交，用户可取回代币。过期按时间戳判断。
   验收：取消或过期后触线不成交，代币能取回。
7. **延迟测量**：脚本跑 30 轮以上，给出全链路延迟的 p50 和 p95。
   验收：README 里有延迟表和原始数据文件。
8. **最小网页**（落后就砍）：用浏览器钱包插件（负责人用 Rainbow）连接；下单（卖 token0，可设止损、止盈、移动止损、有效期）、看自己的订单状态并取消；看最近一次链路的时间线（swap → Lasna reactive 交易 → 成交，带浏览器链接和各段秒数）；另有一个标明"仅测试网演示"的推动价格按钮，方便录视频。放在 GitHub Pages，评委点链接就能打开。
   验收：在 GitHub Pages 上用浏览器插件钱包下一张单，用演示按钮推价格，页面上依次出现三笔交易并显示订单已成交。

## 这一版不做的
- 主网部署，真实资金。
- 多个池子、多跳路由、买入方向的订单（只做"卖出持有的代币"）。
- 部分成交、改单。
- 给他人代管资金的多用户产品化（权限、费用、前端账户体系）。
- 链下 keeper 或任何需要一直在线的服务器。
- 接入中心化交易所。

## 成功标准
- 在活动页按时提交：公开仓库、已部署合约地址、至少 3 组完整链路交易哈希（止损、止盈、移动止损）、3 分钟内的 demo 视频。
- 每组链路的三笔交易都能在区块浏览器上查到，callback 没有报错。
- `forge test` 全部通过。
- 别人照 README 能从头部署并复现一次止损。
- README 里有实测延迟数据。
